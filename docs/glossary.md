## LEAP terms

| Term | Meaning |
|---|---|
| Current Accounts | the calibration scenario (historical years) |
| Key Assumption | a free-standing variable (*Activity Level*) read by other branches |
| Total Activity | product of the activity levels on a branch's path |
| Final Energy Intensity | energy per unit of activity |
| Total Energy | energy entered directly instead of activity × intensity |
| Device Share, Fuel Economy, Mileage, Stock, Sales | vehicle stock-turnover variables |
| Exogenous Capacity | capacity entered by the user (not optimised) |
| Dispatch Rule: FullCapacity / PercentShare | run at full availability in merit order / run by share of output |
| Historical Production | calibration of generation by process |
| Interp, Step, Growth, GrowthAs, LinForecast, ExpForecast, LogisticForecast, Remainder | LEAP time-series functions; `Step` holds a value, `Interp` interpolates, `Remainder` = 100 − siblings |
