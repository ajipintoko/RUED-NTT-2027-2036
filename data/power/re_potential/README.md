# RE potential (utility scale), NTT

| File | Content |
|---|---|
| `RE Potential Map NTT (standalone).html` | Interactive map of renewable-energy potential with grid integration for NTT. Open in a browser; it is self-contained (needs no server). |
| `RE Utility Scale Potential Site.xlsx` | Site compilation (Wind, Solar, Hydro sites) with the assumptions behind the map (transmission-line assumption, EIRR, GIS criteria). Original name: `Result - Site Compile (Solar, Wind, Hydro).xlsx`. |

Use: candidate sites and potential for the `Candidate` processes of the on-grid module and for the Plexos runs ([docs/power-plexos.md](../../../docs/power-plexos.md)).
